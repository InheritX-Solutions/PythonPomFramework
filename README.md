# Playwright Automation Framework (Python - POM)

## Overview
A modern UI Automation Framework built using Playwright with Python, designed using the Page Object Model (POM) architecture. This framework is fast, scalable, and suitable for real-world automation testing.

---

## Tech Stack
- Python  
- Playwright  
- Pytest  
- Allure Reports  

---

## Key Features
- Page Object Model (POM) design pattern  
- Modular and scalable framework structure  
- Reusable base methods (common actions)  
- Data-driven testing (Google Sheets / JSON support)  
- Automatic screenshot capture on failure  
- Allure reporting integration  
- Logging system for debugging and traceability  
- Config-driven environment setup
